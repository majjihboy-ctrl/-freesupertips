📱 Responsive Image Containers

Image sizing across breakpoints:

Desktop (1200px+):
  • Team logos: 80px × 80px
  • Match banners: Full width, 200px height
  • Table icons: 24px × 24px
  • Flag badges: 24px × 16px
Tablet (768px - 1199px):
  • Team logos: 60px × 60px
  • Match banners: Full width, 160px height
  • Table icons: 20px × 20px
Mobile (< 768px):
  • Team logos: 50px × 50px
  • Match banners: Full width, 120px height
  • Table icons: 18px × 18px
  • Stack layout: Single column, full-width cards

CSS Media Query Example:

@media (max-width: 768px) { .team-logo { width: 50px; height: 50px; font-size: 1.5rem; } .match-banner { height: 120px; font-size: 1.5rem; } .match-card { margin-bottom: 1rem; } }

⚡ Image Optimization

File Formats

  • SVG: Team logos, icons, badges (scalable, small filesize)
  • WebP: Match banners, photos (modern compression)
  • PNG: Fallback for WebP (transparency support)
  • JPEG: Only for complex photo content

Performance Checklist

  • ✓ Use <picture> element for format switching
  • ✓ Add loading="lazy" to images below fold
  • ✓ Set explicit width/height to prevent layout shift
  • ✓ Compress images: ImageOptim or TinyPNG
  • ✓ Cache headers: 30 days for static logos
  • ✓ Srcset for responsive images: 1x, 2x variants

HTML Example:

<picture> <source srcset="logo.webp" type="image/webp"> <source srcset="logo.png" type="image/png"> <img src="logo.png" alt="Team logo" width="80" height="80" loading="lazy"> </picture>

♿ Accessibility Guidelines

Alt Text Examples:
  • Team logo: "Manchester United logo"
  • Prediction badge: "Over 2.5 goals prediction, 74% confidence"
  • Match banner: "Barcelona vs Real Madrid"
  • Flag icon: "Spain - La Liga"
Color Contrast:
  • Text on badge backgrounds: WCAG AA compliant (4.5:1 ratio minimum)
  • Green #236b45 on white: 7.2:1 ✓ Excellent
  • Gold #c19143 on white: 4.8:1 ✓ Good
  • Avoid color alone: Always pair with icons or text

🌙 Dark Mode Images

Adjustments for dark theme:
  • Increase opacity of shadow effects: 0.4 instead of 0.1
  • Border colors: Use gold with 0.2 opacity
  • Badge backgrounds: Slightly more saturated
  • Match banner: Keep gradient consistent
  • Test contrast: Ensure readability on dark surfaces

CSS Dark Mode Override:

[data-theme="dark"] { --img-shadow: 0 2px 8px rgba(0,0,0,0.4); --img-border: rgba(193,145,67,0.2); --badge-bg-green: rgba(35, 107, 69, 0.25); } [data-theme="dark"] .team-card { background: rgba(255,255,255,0.05); border-color: rgba(193,145,67,0.2); }
